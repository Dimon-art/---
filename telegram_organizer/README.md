# Telegram Organizer

Скрипт подключается к **личному аккаунту** Telegram (не к боту) через библиотеку [Telethon](https://docs.telethon.dev/) и проверяет, что авторизация прошла успешно.

## 1. Получить api_id и api_hash

1. Откройте [my.telegram.org](https://my.telegram.org) и войдите по номеру телефона.
2. Перейдите в **API development tools**.
3. Создайте приложение: укажите название и короткое имя (платформа может быть любой, для скрипта подойдёт Desktop).
4. Скопируйте **App api_id** и **App api_hash**. Это ключи вашего приложения, их не нужно публиковать.

`api_id` — целое число, `api_hash` — строка.

## 2. Создать файл .env

В каталоге `telegram_organizer` создайте файл `.env` (он указан в `.gitignore` и не попадает в git):

```env
API_ID=123456
API_HASH=your_api_hash
PHONE=+79991234567
```

`PHONE` — номер в международном формате, с плюсом и кодом страны.

## 3. Установка и запуск

Из каталога `telegram_organizer`:

```bash
python -m pip install -r requirements.txt
python main.py
```

Нужен Python 3.10 или новее.

При первом запуске Telethon запросит код подтверждения, который придёт в Telegram. Если на аккаунте включена двухэтапная проверка, скрипт дополнительно спросит пароль. После успешного входа сессия сохраняется в файл `organizer_session.session`, и код больше не нужен, пока сессия действительна.

В консоли появится строка:

```text
Подключение успешно. Пользователь: <имя>
```
